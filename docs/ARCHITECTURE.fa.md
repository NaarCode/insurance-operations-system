# نمای فنی معماری

## اجزای سامانه

- **پنل مدیریت:** Next.js و React برای مدیریت مشتریان، بیمه‌نامه‌ها، درخواست‌ها، تمدیدها و کاربران.
- **API مرکزی:** Express و TypeScript برای گردش‌کار درخواست، کنترل دسترسی، اعتبارسنجی، ثبت فعالیت و مدیریت مدارک.
- **لایه داده:** PostgreSQL و Prisma برای مدل‌های کاربران، مجوزها، مشتریان، خودروها، بیمه‌نامه‌ها، درخواست‌ها و تاریخچه وضعیت.
- **پیام‌رسانی:** ربات بله، مدیریت گفتگو، ارتباط شناسه مخاطب و ارسال پیام.

## جریان درخواست

مشتری درخواست را از طریق ربات ثبت می‌کند. API اطلاعات را بررسی و ذخیره می‌کند. کاربر مجاز در پنل، درخواست را بررسی و وضعیت آن را به‌روزرسانی می‌کند. تاریخچه تغییرات نگهداری می‌شود و در مسیرهای پیش‌بینی‌شده، امکان اطلاع‌رسانی از طریق ربات وجود دارد.

## مرزهای فنی و امنیتی

بررسی هویت و مجوز، سیاست‌های پیوست و ثبت رویداد در سمت سرور انجام می‌شود. مسیرهای خصوصی API، ساختار کامل دیتابیس، رمزها و تنظیمات استقرار عمداً منتشر نشده‌اند.

این متن بر اساس ساختار سورس است و به معنی ممیزی امنیت یا تأیید مستقل محیط عملیاتی نیست.
