# Security and publication scope

This public repository contains documentation and a conceptual architecture illustration only. It excludes operational source code, customer identities, national identifiers, phone numbers, policy documents, attachments, tokens, environment files, database exports, and deployment configuration.

The supplied project was reviewed at the source-structure level; this does not certify deployed-system security.

No customer name, identifying brand artwork, or production screenshots appear in this public showcase. Third-party trademarks remain with their owners.

Please report security concerns privately via [NaarCode](https://naarcode.com/fa).
